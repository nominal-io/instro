The [`NIDAQDriver`](https://nominal-io.github.io/instro/instruments/generated/instro.daq.drivers.ni.nidaq.NIDAQDriver/) provides a driver that can be used to instantiate an [InstroDAQ](/daq).

## Creating an [`InstroDAQ`](/daq) with [`NIDAQDriver`](https://nominal-io.github.io/instro/instruments/generated/instro.daq.drivers.ni.nidaq.NIDAQDriver/)

```python
from instro.daq import InstroDAQ
from instro.daq.drivers.ni import NIDAQDriver

# device name from NI-MAX
daq = InstroDAQ(name="niDAQ", driver=NIDAQDriver(device_id="Dev1"))
```
