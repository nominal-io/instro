### Quickstart
```python
from instro.daq.drivers import NIDAQDriver,LabJackTSeriesDriver
from instro.daq import InstroDAQ

daq = InstroDAQ(
  name    = "myDAQ", 
  driver  = LabJackTSeriesDriver(device_id="1234") 
  #driver = NIDAQDriver(device_id="Dev1") # swap drivers, same code
  )
daq.open() 
measurement = daq.read_analog()
```

### Purpose
The test and measurement field has long been plagued by *reinventing the wheel*, leading to immense  costs. `instro` is an [open-source](https://github.com/nominal-io/instro) Python library for interfacing test and measurement hardware from one unified, typed API. It provides virtual instruments that are **vendor-agnostic**. In addition, `Publishers`  allow  data to be automatically streamed to a file, [Nominal](https://nominal.io), or a destination of your own.
